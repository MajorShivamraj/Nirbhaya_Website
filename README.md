# NIRBHAYA – Smart Women Safety Band

### An Intelligent Wearable Personal Safety Solution

NIRBHAYA is an IoT-based wearable safety system designed to help individuals during emergency situations. It aims to detect potential distress and initiate emergency alerts without requiring the user to access a smartphone.

The project combines intelligent distress detection, offline voice activation, manual SOS functionality and multiple communication pathways to make emergency assistance more accessible and responsive.

## Key Features

- Automated distress detection.
- Offline voice-based emergency activation.
- Manual SOS alert functionality.
- GSM-based emergency communication.
- LoRa-based alternative communication.
- Emergency cancellation and alert feedback.
- Independent location tracking as a planned enhancement.
- Future integration with public transport and emergency-response infrastructure.

## How It Works

NIRBHAYA monitors potential distress situations through its sensing mechanisms. When an emergency is detected or manually activated, the system initiates an SOS alert through its communication modules.

The proposed system will further support location updates and centralised emergency coordination, helping trusted contacts and relevant authorities respond more effectively.

## Technology

- Internet of Things (IoT)
- Embedded Systems
- Wireless Communication
- Sensor-Based Monitoring
- GSM and LoRa
- GNSS-based Location Tracking (planned)
- AIS-140 and ERSS-112 Integration (future scope)

## Current Status

NIRBHAYA has reached the tested-prototype stage. Initial hardware and communication testing has been completed, along with a demonstration on the college campus. Further development, field validation and institutional integrations are planned.

## Future Scope

- Independent real-time location tracking.
- 4G connectivity and improved communication.
- BLE-based public transport identification.
- AIS-140 transport infrastructure integration.
- ERSS-112 emergency response integration.
- Centralised incident monitoring and coordination.
- Expansion across educational institutions and communities.
